# Contributing to Project Chronos

Thank you for your interest in Project Chronos.

Project Chronos is an independent, open scientific research initiative exploring autonomous artificial intelligence, scientific discovery, information preservation, distributed computing, and the physics of time.

We welcome contributions from researchers, engineers, developers, students, and independent contributors around the world.

You do not need to belong to a university or research institution to participate.

## 1. Ways to Contribute

There are several ways to support the project:

### Software Development
- Develop and improve Chronos software.
- Build AI integrations and research agents.
- Improve persistent memory and knowledge management.
- Develop distributed communication systems.
- Improve installation and deployment tools.

### Scientific Research
- Review scientific literature.
- Propose research questions and hypotheses.
- Develop mathematical or computational models.
- Design reproducible experiments.
- Review existing research and identify limitations.

### Engineering and Hardware
- Improve Raspberry Pi deployment.
- Develop hardware interfaces.
- Investigate low-cost computing infrastructure.
- Improve reliability, energy efficiency, and data preservation.

### Documentation and Community
- Improve technical documentation.
- Translate project materials.
- Report errors and suggest improvements.
- Help new contributors understand the project.

## 2. Before Contributing

Please read the following documents:

- [Founding Manifesto](docs/manifesto.md)
- [Development Roadmap](docs/development-roadmap.md)
- [Scientific Principles](docs/scientific-principles.md)
- [Technical Architecture](docs/architecture.md)

Contributions should support the project's mission and respect its scientific principles.

## 3. Proposing an Idea

If you have a research idea, technical proposal, or improvement:

1. Open the GitHub Issues section.
2. Create a new issue.
3. Give it a clear and descriptive title.
4. Explain the problem or proposed idea.
5. Include references, evidence, or examples where appropriate.

Scientific proposals should distinguish established knowledge from theoretical possibilities and speculation.

## 4. Contributing Code

When software development begins, contributors should:

1. Fork the repository.
2. Create a separate branch for their changes.
3. Make focused and documented modifications.
4. Test their changes where possible.
5. Submit a Pull Request.
6. Explain the purpose and technical details of the contribution.

Contributors should avoid including passwords, API keys, private credentials, or sensitive personal information in commits.

## 5. Scientific Contributions

Scientific contributions should include:

- Research question.
- Background and relevant literature.
- Assumptions and methodology.
- Mathematical or computational details where applicable.
- Results and limitations.
- References and supporting evidence.

AI-generated hypotheses are welcome as research proposals, but they must not be presented as verified scientific discoveries without appropriate independent validation.

## 6. Review and Acceptance

Contributions may be reviewed for:

- Technical correctness.
- Scientific consistency.
- Reproducibility.
- Security and reliability.
- Relevance to the project.
- Clarity and documentation.

Constructive disagreement is encouraged.

Not every proposal will be accepted, and rejection of an idea does not imply rejection of its contributor.

## 7. Community Conduct

All contributors are expected to:

- Treat others with respect.
- Welcome constructive criticism.
- Avoid harassment and discrimination.
- Respect intellectual contributions and acknowledge sources.
- Discuss disagreements professionally.
- Prioritize evidence over personal beliefs.

## 8. Questions

If you are unsure how to contribute, open a GitHub Issue describing your interests and relevant experience.

We welcome people who want to learn as well as those who already have technical or scientific expertise.

## Final Note

Project Chronos begins with a small number of contributors, but its long-term vision is international collaboration.

Every meaningful contribution, whether a line of code, a scientific review, an experiment, or a well-founded criticism, can help move the project forward.

**The work begins with one node. The vision belongs to humanity.**
